# Таблица ролей и полномочий Kubernetes

| Роль     | Полномочия                                                                 | Группы пользователей         |
|----------|-----------------------------------------------------------------------------|------------------------------|
| viewer   | Просмотр всех объектов в namespace, нет прав на изменение                 | аналитики, тестировщики      |
| operator | Изменение объектов, запуск/перезапуск подов, но без доступа к secret      | разработчики, devops         |
| admin    | Полный доступ к объектам, включая secret и конфигурации                   | администраторы, security     |
